Various Themes

100 themes for Omarchy. Each theme has a night and a day variant, and every screenshot is a real desktop.

Install

install.sh copies themes into ~/.config/omarchy/themes. It installs the night and the day variant of a theme unless you pick one with --variant. It never replaces a theme that you made.


    

    

      
Theme names end in -night or -day, for example kyoto-moss-night. Other options: --all, --list, --update, --remove, --link and --force. Run install.sh --help for details.

      
To apply a theme at once, open it and select Apply with Aether. Aether downloads colors.toml and a 3840x2160 copy of the background. Install as Omarchy theme adds the variant to the Omarchy theme menu.
